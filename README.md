This is **NexusDoom**, a Doom source port derived from [DSDA-Doom](https://github.com/dsda-org/dsda-doom), with network code is copied from [Woof!](https://github.com/fabiangreffrath/woof). The goal of this source port is to add multiplayer support specifically for tool-assisted speedruns.

Be aware that the adaptation is almost entirely vibe-coded. Although I am a professional programmer, my only experience is with full-stack _web_ development.
